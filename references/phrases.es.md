# Frases a eliminar (castellano)

## Aperturas de carraspeo

Quita estos anuncios. Afirma el contenido directamente.

- "Lo cierto es que…"
- "La verdad es que…"
- "Lo que pasa es que…"
- "A ver…" / "Vamos a ver…"
- "Para que nos entendamos…"
- "Dicho esto…"
- "Llegados a este punto…"
- "Sin más preámbulos…"
- "Permíteme explicar…" / "Déjame explicarte…"
- "Cabe destacar que…" / "Cabe señalar que…" / "Cabe mencionar que…"
- "Es importante destacar/señalar/mencionar que…"
- "Resulta interesante notar que…"
- "Voy a ser sincero/honesto…"
- "Que quede claro:"
- "Hablemos de…" / "¿Podemos hablar de…?"

Cualquier construcción tipo "lo cierto es que / la verdad es que / lo que pasa es que" es carraspeo antes de la idea. Córtala y suelta la idea.

## Muletillas de énfasis

No añaden significado. Bórralas.

- "Punto." / "Y punto." / "Y ya está."
- "Que quede claro."
- "Para que te hagas una idea."
- "Que no se te olvide."
- "No te equivoques."
- "Esto importa porque…"
- "Y aquí es donde está la clave."

## Jerga corporativa

Sustituye por lenguaje plano.

| Evita | Usa en su lugar |
|-------|-----------------|
| Poner en valor | Mostrar, destacar |
| Potenciar/generar sinergias | Cooperar, combinar |
| Alinear / alineamiento | Acordar, coincidir |
| Accionable | Útil, concreto |
| Ecosistema | Entorno, sector |
| Hoja de ruta | Plan |
| Palanca de cambio | Causa, motor |
| Profundizar en | Analizar, examinar |
| Abordar el reto/desafío | Afrontar, atender |
| Navegar la incertidumbre | Manejar, gestionar |
| Empoderar | Dar autonomía |
| Apostar por | Elegir, optar por |
| Doblar la apuesta | Insistir, intensificar |
| Dar un paso atrás | Reconsiderar |
| De cara a | Para |

| Tejer / forjar [algo] | Nombrar la acción concreta |

| Aterrizar la idea | Concretar |
| Bajar al terreno | Concretar |
| Poner el foco en | Centrarse en |
| Visibilizar | Mostrar, enseñar |

## Adverbios

Mata todos los adverbios en **-mente**. Sin suavizadores, sin intensificadores, sin hedging.

Reincidentes específicos:

- realmente
- simplemente
- básicamente
- fundamentalmente
- evidentemente
- claramente
- obviamente
- naturalmente
- prácticamente
- ciertamente
- honestamente / francamente / sinceramente
- profundamente / esencialmente
- generalmente / principalmente / especialmente / particularmente
- totalmente / completamente / absolutamente
- precisamente

También corta estos rellenos:

- "justo" (como muletilla: "justo eso", "justo ahora")
- "solo" (cuando es muletilla, no cuantificador)
- "literalmente" / "en serio" / "de verdad"
- "un poco" / "algo" / "más bien" (hedging)
- "Al final del día"
- "En el fondo"
- "A día de hoy" / "Hoy en día" / "En estos tiempos"
- "En el mundo actual" / "En el contexto actual"
- "Vale la pena mencionar/señalar"
- "Cuando se trata de"
- "En lo que respecta a" / "En cuanto a" (cuando es relleno)
- "En última instancia"
- "En definitiva"

## Meta-comentarios

Quita los apartes autoreferenciales. El texto debe avanzar, no anunciar su propia estructura.

- "Pista:" / "Spoiler:" / "Atención:"
- "Ya lo sabes, pero…" / "Como ya sabes…"
- "Pero eso es otra historia."
- "X es una característica, no un fallo."
- "Disfrazado de…"
- "En el resto del texto veremos…"
- "Déjame guiarte por…" / "Te voy a guiar por…"
- "En este apartado vamos a…" / "En esta sección…"
- "Como veremos a continuación…" / "Más adelante explicaré…"
- "Quiero explorar…" / "Vamos a explorar…"
- "Te voy a contar…" / "Voy a hablarte de…"

## Énfasis performativo

Falsa intimidad o sinceridad fabricada:

- "Te lo prometo."
- "Lo digo en serio."
- "Existen, te lo aseguro."
- "Por loco que parezca…"
- "Aunque suene raro…"

## Decir en lugar de mostrar

Anunciar la dificultad o importancia en vez de demostrarla:

- "Esto es realmente difícil."
- "Esto es lo que de verdad significa X."
- "Esto es liderazgo de verdad."
- "Esto sí que importa."

## Declarativas vagas

Frases que anuncian importancia sin nombrar la cosa concreta. Mátalas.

- "Las razones son estructurales."
- "Las implicaciones son significativas."
- "Esto es el problema de fondo."
- "Lo que está en juego es enorme."
- "Las consecuencias son reales."
- "El impacto es profundo."
- "Es algo a tener muy en cuenta."

Si una frase dice que algo es importante/profundo/estructural sin mostrar la cosa concreta, córtala o sustitúyela por la cosa concreta.
